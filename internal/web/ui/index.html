Connect your Telegram account

tgvault talks to Telegram with your own API keys. Get them once:

  1. Open my.telegram.org and log in.
  2. Choose API development tools and create an app (any name).
  3. Copy the api_id and api_hash here.

These stay on this computer. Never share them.

Log in to Telegram

Use the number your Telegram account is on, with the country code.
