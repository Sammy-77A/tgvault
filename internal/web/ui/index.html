Connect your Telegram account

tgvault talks to Telegram with your own API keys. Get them once:

  1. Open my.telegram.org and log in.
  2. Choose API development tools and create an app (any name).
  3. Copy the api_id and api_hash here.

These stay on this computer. Never share them.

Log in to Telegram

Use the number your Telegram account is on, with the country code.

Scan with your phone

  1. Open Telegram on your phone.
  2. Go to Settings → Devices → Link Desktop Device.
  3. Point your phone at this code.

Is this a code project?

These folders look like code projects. A project is backed up as one ZIP (fast, tidy, keeps the last 3 versions). Rebuildable folders like node_modules and vendor are left out. Until you choose, tgvault leaves these folders alone.
